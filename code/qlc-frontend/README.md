# QLC Frontend

This directory contains the frontend for the Questions on Learner's Code (QLCs) website application used in the study.

## Overview

The frontend is built with React, TypeScript, and Vite. It provides the user interface for the study web app and communicates with the backend API.

## Prerequisites

- Node.js 20 or later
- npm

## Install Dependencies

From this directory, install the project dependencies:

```bash
npm install
```

## Run the Web App

Start the development server:

```bash
npm run dev
```

Vite will print a local URL in the terminal. Open that address in your browser to use the app.

## Other Useful Commands

Build the frontend for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Run the linter:

```bash
npm run lint
```

## Notes

If the frontend depends on environment variables or a running backend service, make sure those are configured before starting the app.
