# Research Project Repository

This repository collects the materials associated with a research study about Questions on Learner's Code (QLCs).

## Repository Contents

- `code/` contains the website application used during the study, including both the frontend and backend components.
- `recruitment/` contains the materials used to recruit students, including the presentation and user manual.
- `analysis/` contains Colab notebooks and rendered PDFs summarizing the results of the notebooks.

## Data Availability

The data collected during the study could not be released. The student code cannot be published on the Internet, even if identifying information is redacted, due to an affiliated institution's policies regarding student assignments. The generated QLCs from the study were also not included; even if they are anonymized, the content being discussed by the questions could potentially be traced to the assignments used in the CS1 course, and by extension, the students themselves.
## Notes

This repository is organized to support transparency around the study materials that can be shared while respecting privacy, confidentiality, and review constraints.
